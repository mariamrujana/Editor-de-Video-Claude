# Formatos de MUMI RUJANA

Los cuatro comparten la misma marca (colores, tipografías, texturas), pero cada uno se cuenta y se edita distinto.

| Carpeta | Formato |
|---|---|
| `blog-y-desarrollo/` | Blog y desarrollo |
| `mumi-data/` | Mumi Data |
| `the-office-home/` | The Office Home |
| `musica/` | Música |

En cada carpeta:
- `formato.md` → cómo se cuenta y cómo se edita ese formato
- `referencias/` → videos de ejemplo (no se suben a GitHub por su peso)
- `proyectos/` → un proyecto por video, copiando `AAAA-MM-nombre-del-proyecto`
